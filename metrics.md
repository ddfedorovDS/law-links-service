# Метрики качества

Оценка выполнена скриптом `evaluate.py`. Ссылка верна, только если совпали все четыре поля; TP, FP, FN суммируются по всем текстам набора (микроусреднение).

## Версии алгоритма

| Версия | Коммит | Что изменилось |
|---|---|---|
| v1 | «алгоритм извлечения ссылок» | первая рабочая версия |
| v2 | «исправления по ошибкам слепой проверки» | названия через дефис, «п.п.», «стат.», буквы со скобкой |
| v2.1 | «fix of false-positive» | маркеры только в своих словоформах: «статус», «частично», «пунктир» больше не считаются маркерами; на наших наборах метрики как у v2 |
| v3 | «устойчивость к опечаткам и небрежной записи» | включает v2.1; нечёткое сравнение названия сразу после цепочки, маркеры без точки, отделение приклеенного номера |

## Сводка: ссылки целиком

| Набор | Текстов / ссылок | v1 F1 | v2 F1 | v3 Precision | v3 Recall | v3 F1 |
|---|---|---|---|---|---|---|
| dev | 28 / 34 | 1.000 | 1.000 | 1.000 | 1.000 | 1.000 |
| holdout | 37 / 41 | 1.000 | 1.000 | 1.000 | 1.000 | 1.000 |
| слепая | 50 / 61 | **0.836** | 0.948 | 0.982 | 0.902 | 0.940 |
| зашумлённая (seed 0) | 98 / 136 | 0.676 | 0.719 | 0.992 | 0.956 | 0.974 |
| зашумлённая (seed 1) | 98 / 136 | 0.719 | 0.745 | 0.992 | 0.949 | 0.970 |

Первый прогон v1 на слепой выборке подробно: precision 0.939, recall 0.754, F1 0.836 (TP 46, FP 3, FN 15). По актам: precision 1.000, recall 0.867.

Метрики работающего сервиса в Docker (`python evaluate.py --url http://localhost:8978/detect`) совпадают с метриками алгоритма, вызванного напрямую.

## Как читать эти цифры

- **dev** — обучающая выборка в прямом смысле: правила писались по этим предложениям.
- **holdout** — фразы были прочитаны при уточнении правил разметки до написания алгоритма, поэтому результат оптимистичен.
- **Слепая выборка, v1** — фразы предоставил участник команды, не участвовавший в написании правил и алгоритма; разметка сделана до запуска алгоритма; алгоритм был зафиксирован в репозитории до получения фраз. **Это основная оценка качества: F1 = 0.836.** Значения v2 и v3 на этой выборке оптимистичны: исправления v2 делались по её ошибкам.
- **Зашумлённая выборка** — синтетическая: те же фразы из dev, holdout и слепой выборки, в каждой опечатка в одном слове названия закона и ещё один вид небрежности (маркер без точки, без пробела, номер приклеен к названию, случайный регистр). Генерируется `make_noisy.py`. Улучшения v3 настраивались на seed 0; вариант с seed 1 при настройке не использовался и показывает, что результат не подогнан под конкретные опечатки. Это проверка устойчивости, а не независимая оценка качества: фразы те же самые.

Профиль ошибок: высокая точность при более низкой полноте. Если алгоритм вернул ссылку, она почти всегда верная, а основная потеря — пропуски.

## Скорость

Индекс названий строится при запуске сервиса, около 1 секунды. Обработка 2000 текстов алгоритмом (v3): около 6 секунд при длине около 1000 символов, около 20 секунд при длине около 4000 символов. Через HTTP 2000 запросов по ~1000 символов — порядка 10 секунд.
